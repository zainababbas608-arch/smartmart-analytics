# SmartMart Retail Analytics

SQLite + Streamlit Community Cloud analytics project.

> Data generation and cleaning are implemented. SQL and dashboard files remain placeholders.

## Structure

```text
smartmart-analytics/
├── app.py
├── sql/
│   ├── schema.sql
│   └── kpi_queries.sql
├── src/
│   ├── __init__.py
│   ├── db.py
│   ├── transforms.py
│   ├── kpis.py
│   └── charts.py
├── scripts/
│   ├── generate_data.py
│   ├── clean_validate.py
│   ├── build_database.py
│   └── verify_kpis.py
├── data/
│   ├── raw/
│   ├── clean/
│   ├── quality/
│   └── smartmart.db
├── tests/
├── .gitignore
├── README.md
└── requirements.txt
```

`data/smartmart.db` is generated by `scripts/build_database.py` and is
git-ignored. The clean CSVs remain the reproducible source of truth.

## Planned pipeline

1. `scripts/generate_data.py` creates synthetic raw CSVs.
2. `scripts/clean_validate.py` validates and cleans them.
3. `scripts/build_database.py` loads clean CSVs into SQLite.
4. `app.py` serves the dashboard from SQLite.
5. `scripts/verify_kpis.py` reconciles SQL and pandas KPI totals.

## Local setup

```bash
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
py scripts/generate_data.py
py scripts/clean_validate.py
streamlit run app.py
```

No cloud database or credentials are required. The SQLite database is built
locally from the cleaned CSV files.
